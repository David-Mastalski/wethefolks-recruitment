# Project: Flappy Bird Playable Ad (Vanilla JS)

## Tech Stack & Constraints
- Pure HTML5, CSS3, Vanilla JavaScript (ES6+).
- NO external frameworks, bundlers (Vite/Webpack), or npm dependencies unless requested.
- Assets are located in `./assets/images` and `./assets/audio`.
- Code must be clean, modular, and performance-optimized (use `requestAnimationFrame`).

## Code Style & Standards
- Keep HTML, CSS, and JS separated (`index.html`, `style.css`, and modular JS scripts).
- Use Object-Oriented or Module Pattern for game logic (e.g., `Game`, `Bird`, `Pipe`, `AudioController`).
- Document key functions in English.
- Responsive canvas/container scaling for mobile and desktop preview.
